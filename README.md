# Deepsekaggler

Agente para la competición de Kaggle **Kaggriculture** (Lux AI Season 3).

## Estrategia

- **Partida 1**: Exploración del mapa para descubrir nodos de reliquia, nodos de energía y estimar parámetros del juego.
- **Partidas 2-5**: Explotación maximizando puntos en nodos de reliquia y atacando al oponente cuando es ventajoso.

## Cómo subir a Kaggle

```bash
tar -czvf submission.tar.gz agent.py main.py
